# static_site_generator
A simple **static site generator** similar to https://gohugo.io/.

## How to use
1. Upload your _markdown files_ to the **content** directory
2. and your _css styling and images_ to the **static** directory.
(```For instance you can check the mentioned directories in this project.```)
3. Run `./main.sh` in cmd.

The generated sites in this project can be checked [here](https://samiri123.github.io/static_site_generator/)
